# 使用管理台

<div class="shot"><img src="/console-overview.zh.png" alt="概览"></div>

## 概览

- **服务中的会话**：有启用订阅的私聊、群组、频道数量。
- **订阅**：启用与暂停的数量、订阅源数量。
- **累计推送**：成功推送的篇次与新文章数（从启用管理台后开始统计）。
- **需要处理**：连续抓取失败次数达到阈值的订阅。
- **推送趋势**：24 小时、7 天按小时，30 天按天；鼠标悬停看具体数字。

## 会话

列出所有使用机器人的会话。点“管理”打开详情面板：

- **概况与权限**：设置角色（管理员 / 用户 / 访客 / 已封禁）。封禁会暂停这个会话的全部订阅并拒绝它之后的命令；群组和频道可以“让机器人退出”。
- **订阅**：这个会话的订阅，可导入 / 导出 OPML。
- **推送默认值**：等同于机器人里的 `/set_default`，对选择“跟随会话默认”的订阅生效。
- **操作记录**：这个会话在机器人里用过的命令、网页上做过的修改。

默认不显示已封禁的会话，用右上角的筛选切换。

私聊用户的名称在对方给机器人发消息时记录；管理台上线前就在用的用户，启动时会从机器人的 Telegram 会话里补全，也可以点“补全名称”。查不到的显示为“用户 123456”。

## 订阅

按标题、网址、会话、状态筛选。勾选后底部的操作条可以批量：暂停、恢复、**立即抓取**（逐个抓取所选的源，有新文章照常推送）、设置检查**间隔**、设置**代理**、**复制地址**、导出或取消订阅。点击订阅打开详情：

- **设置**：自定义标题、hashtag、检查间隔、推送格式（文字与机器人 `/set` 菜单一致）。
- **接收会话**：这个 RSS 源推送到哪些会话。增减会话即可，不用再 `/unsub` 后 `/sub`；同一个源只抓取一次。
- **最近文章**：最近 20 篇文章及其推送到当前会话的结果。
- **抓取**：立即检查更新并推送、测试推送最新一篇；为这个源单独设置**代理**（跟随全局 / 直连 / 使用代理，可先“测试这个设置”）和 User-Agent。选中多个订阅后，底部的“代理”可以批量设置。
- **日志**：默认显示“抓取记录”——这个源每次抓取的时间、耗时、读到多少篇、新增多少篇；结果相同的连续检查合并成一行（如“共 53 次检查 · 有效 36 条 · 新增 0 条”），有变化才新增一行。另一个标签“事件与推送”显示失败原因、有更新、恢复和推送结果。每个源保留的行数可在“设置 → 订阅规则”里调整（默认 20 行）。

## 运行日志

有两个视图：“事件”是抓取失败、推送异常、通知发送和系统事件；“抓取记录”是所有订阅源的每次抓取（可按有新文章、成功、失败筛选）。事件每条都直接写出原因，例如：

- `HTTP 403 · 网站拒绝访问，可能拦截了机器人（可尝试更换 User-Agent）`
- `连接超时，网站响应太慢或无法访问`
- `返回内容不是有效的 RSS/Atom`
- `机器人没有在这个会话发消息的权限，或已被移出/屏蔽`

没有新文章的正常检查不会逐条记录。

## 通知

“设置 → 通知”：

- **通过本机器人发给我**：最省事，机器人直接私聊所有者（需要你先对机器人发过 `/start`）。
- 也支持另一个 Telegram 机器人、Bark、ntfy、Webhook。
- 可以在订阅源连续失败 N 次、恢复正常、有新会话开始使用机器人时通知。通知里写明订阅源名称、链接、失败次数，或者新会话的名字，并附管理台链接。

## 设置里的其他内容

- **订阅规则**：默认 / 最短检查间隔、订阅上限（等同于 `/set_option`）。
- **运行配置**：原本写在部署环境里的配置，网页上可改，显示当前生效值和来源；按类别折叠成组，可搜索设置名、变量名或说明，说明点设置名旁边的 ⓘ 弹出；Telegraph Token 可一键获取。保存后重启生效，可直接点“立即重启”。
- **备份与恢复**：导出备份；上传备份先预检，再暂存到下次重启时恢复。
- **API 访问**：为脚本或 AI Agent 创建令牌，见 [API 与 Agent](./api)。
- **账户与安全**：修改账号和密码、退出所有设备、立即重启机器人。登录页需要账号和密码（首次登录账号是 `admin`，密码是 `WEB_PASSWORD`），浏览器和 iCloud 钥匙串可以直接保存。
