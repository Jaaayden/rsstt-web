features:
  - title: See who the bot serves
    details: Private chats, groups and channels at a glance. Set roles, block strangers, make the bot leave, and get notified when a new chat starts using it.
  - title: One feed, many chats
    details: A feed is fetched once and delivered to every chat that wants it. Add or remove recipients on the web instead of /unsub and /sub.
  - title: Failures, explained
    details: Logs say whether it was HTTP 403, a timeout or an invalid feed. Fetch now or send the latest post as a test.
  - title: Alerts in Telegram
    details: Failing feeds, recoveries and new chats — the bot messages you directly. Bark, ntfy and webhooks too.
  - title: Your data, reversible
    details: Fully compatible with the original bot's database. Migrate without duplicate posts and switch back at any time.
  - title: Light, one image
    details: One Docker image, no front-end build. Measured with 429 feeds, about 5 MB more memory than the original bot.
